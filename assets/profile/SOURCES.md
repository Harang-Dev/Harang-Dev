# Profile assets

- Technology icons: https://github.com/tandpfun/skill-icons — MIT.
- Pikachu animation: https://tenor.com/view/pikachu-pokemon-waving-wave-hi-gif-16091246
- 3D contribution rendering: https://github.com/yoshi389111/github-profile-3d-contrib — MIT.
- Contribution data: public GitHub profile calendar, 2025-09-07 through 2026-09-10; 2,731 contributions.
- Link badges and career roadmap: custom vector assets for this profile.
- Career map scenery is a static 2.5D SVG, generated with scripts/render_career_map.py. Career labels and organization logos are laid out as native README HTML.
- Career roadmap reflects Tongmyong University and current employment at AlphaPrime. Dates are intentionally omitted.

The contribution image is a snapshot generated on 2026-09-10.

## Official logos

- Tongmyong University Korean signature: https://www.tu.ac.kr/tuhome/sub01_02_06_01.do — PNG signature package, horizontal Korean version.
- AlphaPrime white wordmark: https://alphaprime.co.kr/_nuxt/alphaprimeTextLogoWhite.bc46a5c6.png — official company website header.
- Source PNG files are preserved unchanged in logos/. The *-label.png display assets place each logo on a contrasting background at its original aspect ratio, exported at 4× display resolution using @resvg/resvg-js 2.6.2. Logos are referenced directly by README HTML, not embedded in the SVG.
